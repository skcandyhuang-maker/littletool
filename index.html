一次體檢，走過哪四步

工具的核心邏輯很像帶客戶做「網站健康檢查」：輸入網域、機器跑一輪檢查、結果存檔累積、你再把發現轉成對話。

STEP 1

輸入網域

貼上客戶的網址。想精準測某個頁面（例如登入頁）就貼完整網址，只想測整個域名就貼裸網域即可。

STEP 2

系統健檢

依你左側勾選的項目，同時對這個網域跑 DNS、憑證、安全標頭、連線測試共 7 項自動化檢查。

STEP 3

存檔累積

結果自動寫入本機資料庫，同一個網域不會重複洗掉，掃過幾百筆客戶名單也不怕中斷。

STEP 4

報告與對話

下載 CSV 給內部或客戶，或直接在畫面上挑出弱點，帶進你的服務提案。

分頁 01

七項檢查在查什麼

「域名檢測」頁籤左側的勾選框，實際對應下面七件事。工具依你勾的項目跑，沒勾的欄位就維持「-」。

第一組・檢測項目

DNS 解析

查 A 紀錄（IP）跟 CNAME（別名指向）。多筆 IP 代表有做負載平衡；CNAME 裡的關鍵字用來比對是否已掛 CDN。

客戶已用哪家 CDN、或根本沒有防護層，一眼看出。

GeoIP 查詢

把解析出的 IP 拿去查地理位置與 ISP／機房組織，需呼叫外部 API，速度較慢。

主機是不是放在海外、用哪家雲，牽動法遵與延遲話題。

SSL & TLS 憑證

讀憑證發行機構、剩餘天數，並檢查是否支援 TLS 1.3、以及 TLS 1.0/1.1 這兩個舊版本是否還開著。

SSL Days 快到期 是續約商機；TLS 1.0/1.1 未關閉 是法遵風險。

Security Header

檢查 6 個現代安全標頭：HSTS、CSP、X-Frame-Options、X-Content-Type-Options、Referrer-Policy、Permissions-Policy。

同一次檢測也順便判斷「能否被嵌入」（見下方說明）。

Server 標頭偵測

單獨抓 HTTP 回應裡的 Server 欄位，例如 nginx/1.18。與上面六項分開匯出。

版本外洩＝攻擊者能鎖定已知漏洞下手，是很直觀的風險示範。

第二組・連線測試

Simple Ping

從你現在這台主機直接發一次請求，回報狀態碼（200／404／逾時）。

最快速的「網站活著嗎」檢查，現場示範時第一個看的欄位。

Global Ping

透過 Globalping 這個公開節點網路，從國外機房發請求測試，速度較慢。

跨區延遲／可用性的客觀數據，是加速服務的敲門磚。

「能否被嵌入」怎麼來的： 它不是獨立勾選項，是「Security Header」這格勾起來後，順便用 X-Frame-Options 跟 CSP 的 frame-ancestors 判斷出來的——顯示 ❗️是 代表這個網頁可以被放進別人的 iframe 裡，也就是有 Clickjacking（點擊劫持）風險。
現場示範前check一下： 工具會自動跳過「資料庫裡已經存過的域名」，只認網域本身、不認你這次輸入的路徑。如果同一個網域你想換一個頁面路徑重新測，記得先在側邊欄「清空資料庫」，不然畫面顯示的會是舊結果。
分頁 02–05

另外四個頁籤，各自扮演什麼角色

除了主要的域名檢測，工具還有四個頁籤，分別處理「批次驗證」「版本紀錄」「操作說明」跟「現場實證」。

02

IP 反查域名 (VT)

貼一批 IP，透過 VirusTotal 的歷史解析紀錄，反查出這個 IP 曾經被哪些域名指過，並即時驗證這些域名現在是否還指向這個 IP。

怎麼用
  • 輸入 VirusTotal API Key
  • 貼上 IP 清單，逐一查詢（內建 rate-limit 冷卻機制，避免被鎖）
  • 結果自動存檔，畫面下方即時預覽
業務切入點
  • 發現同一個 IP 掛了很多不相干的域名 → 共站風險，鄰居網站出事可能被連坐
  • 反查到的舊域名已經不再指向這個 IP → 客戶可能換過機房/服務商，是重新盤點的時機
05

惡意網站模擬

內嵌一個外部的 Clickjacking 示範工具，把分頁 01 裡「能否被嵌入」的抽象判定，變成一個看得到、點得到的活教材。

怎麼用
  • 如果客戶網域顯示「能否被嵌入」為 ❗️是，直接切到這一頁
  • 畫面若空白，代表目標網站本身有防護、無法被嵌入——這反而是它防護到位的證明
業務切入點
  • 比起唸出「缺少 X-Frame-Options」，讓客戶親眼看到自己的頁面被套進一個假操作介面裡，說服力完全不同
03/04

更新紀錄 ／ 操作手冊

03 是版本異動紀錄，讓你知道這套工具最近新增了什麼、舊版差在哪；04 連到線上操作手冊，遇到不會用的欄位直接查。

話術卡

看到這個結果，這樣接話

下面是最常出現的檢測結果，跟對應的客戶對話切入點。範例 標記的資料為示範用途，非任何真實客戶紀錄。

畫面上看到代表什麼你可以這樣說
能否被嵌入：❗️是分頁 01 網頁沒有設定防嵌入標頭，可被放進他人網站的隱形框架裡誘導點擊。 「我現場示範給您看」→ 切到分頁 05 實測。
TLS 1.0/1.1 未關閉分頁 01 伺服器還接受十幾年前的舊加密協定，等同於門鎖還留著一把過期鑰匙。 對應法規/資安稽核常見要求項目，可帶入資安健檢或憑證代管服務。
SSL Days：18分頁 01 憑證再 18 天到期，逾期未換等於網站直接跳出「不安全」警告。 續約/代管憑證服務的自然開場，時間點明確、急迫性高。
Server：nginx/1.18.0分頁 01 網站主動告訴訪客它跑什麼軟體、什麼版本。 「這個版本網路上查得到已知漏洞」，帶出隱藏版本資訊/WAF 服務。
Security Headers：❌ 無分頁 01 六項現代安全標頭一個都沒設，屬於最基礎的資安體質不足。 用來開場的「體檢報告」——先講體質，再談要不要開處方。
CDN Provider：-分頁 01 網域沒偵測到任何已知 CDN／雲端服務商特徵，等於零防護層直接曝露來源主機。 加速＋防護的入門提案，起手式是「您現在等於沒有前導層」。
同 IP 反查出 6 個域名分頁 02 這台主機同時服務多個不相干網站，屬於共站環境。 鄰站中毒、資源競爭的共站風險，帶出獨立主機/專屬資源的提案。
